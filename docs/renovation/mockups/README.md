# Design-direction mockups

Three treatments of osu!stable's layout: `faithful`, `refined` and `bold`. Each has a main menu and a song select, at 1920×1080.

- Comparison and decision page for the user: https://claude.ai/artifact/WPKRiAu87RZV2pKhaAQncj
- The spec that comes out of the decision: `../DESIGN.md`

The maps, artists, scores and art are invented. The background and thumbnails are generated by `src/make_art.py`, so no beatmap content is used. The logo is a placeholder.

## Regenerate

```
cd docs/renovation/mockups/src
./get-fonts.sh            # Nunito + M PLUS Rounded 1c (OFL) into fonts/ (git-ignored)
python3 make_art.py       # background and thumbnails into art/ (git-ignored, deterministic)
../../../../tools/dev/guarded --mem 6G -- ./render.sh     # headless Firefox -> ../<screen>-<variant>.jpg
```

One page per screen (`mainmenu.html`, `songselect.html`). `?v=faithful|refined|bold` picks the treatment. Shared styles are in `mockup.css`, and icons and helpers in `icons.js`.

The "today" references are in `../screens/before/`, captured from neomod with `tools/screens/capture_before.py`, using the same generated maps and art.
